## 추가 이슈 (2026-08-06)

### No. 13 — EOL 포인트 간 온도편차 관리 spec
- 문제점: EOL 각 포인트 간(1-3, 1-2, 2-3) 온도편차 1℃ 관리 spec 지정 필요
- 원인: 포인트 간 온도편차에 대한 관리기준(spec)이 수립되지 않아 편차 발생 여부 판단 기준 부재
- 대책: 포인트 간 온도편차 1℃ 관리 spec 지정 및 검사 기준 반영 (7/23 예정)
  - 검출 방식: NTC 1-2-3 저항값 측정 → 온도 환산 → NTC 간 편차 검출(3쌍 비교), ≥1.0℃ → NG / 3쌍 모두 1.0℃ 미만 → PASS

### EOL 포인트별 저저항 Spec 지정 검토 (P1 이관 항목)
- 요청사항: EOL 포인트별 저저항 Spec 지정 검토 필요 (도선 길이에 따라 포인트 간 저항 차이 발생하나 offset 기능 없음)
- 생산기술 결과(확정 문구):
  - 현재 저저항 측정 데이터 모수 부족으로 포인트별 Spec 지정 불가
  - P1 생산 진행 중 충분한 측정 모수 확보 후 포인트별 저저항 평균치 및 Min/Max 값 산출 예정
  - 산출 데이터 기반으로 세방 개발팀 및 품질팀 협의 후 포인트별 저저항 관리 Spec 확정 예정
