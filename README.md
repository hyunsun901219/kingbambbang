# 자동차 생산기술 작업 저장소

자동차 생산기술 관련 학습, 문서, 프로젝트 작업물을 정리하는 저장소입니다.

## 저장소 구조

```
├── docs/          # 생산기술 관련 문서, 정리 자료
├── projects/      # 개별 프로젝트 작업물
├── notes/         # 세션별 작업 기록 (날짜별)
└── WORKLOG.md     # 전체 작업 이력 요약
```

## 사용 방법

- 새로운 작업을 시작하면 `WORKLOG.md`에 날짜와 함께 요약을 기록합니다.
- 상세한 작업 내용은 `notes/YYYY-MM-DD-주제.md` 형식으로 저장합니다.
- 문서나 결과물은 `docs/` 또는 `projects/` 아래 주제별 폴더에 저장합니다.

이렇게 해두면 다음 세션에서 Claude가 이 저장소를 읽고 이전 작업 맥락을 이어받을 수 있습니다.
