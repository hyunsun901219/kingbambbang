## 1. 외부 데이터: 지금 시장과 플랫폼은 어떤가

### 1-1. 주제 수요: 시장은 흔들리지만 개인 수요는 계속됨

| 지표 | 값 | 신뢰도 |
|---|---|---|
| 국내 ETF 순자산 | 297조 원(2025년 말) → **533조 원(6/22 고점)** → 434조 원(7월 말, 코스피 -22%) → **447조 원(9/17)** | 교차확인 |
| 개인 ETF 순매수 | **32개월 연속**, 누적 128조 원. 단 8월은 2.4조 원으로 올해 최저 | 교차확인 |
| 하반기 개인 순매수 1위 | TIGER 미국S&P500 (8월 상위 1~4위가 모두 미국지수 ETF) | 교차확인 |
| 방어형 자금 | 파킹형 ETF에 9월 중순 한 주 1.8조 원 유입. 커버드콜 15조 → 27.6조 원. 채권혼합형 +59% | 교차확인 |
| 연금·ISA | 퇴직연금 계좌 ETF 21조(2024) → 48.7조(2025) → 약 60조 원(2026년 2분기). ISA 973만 계좌 중 48.5%가 잔액 1만 원 이하 | 교차확인 |

→ **해석**: 시장은 고점에서 16% 빠졌지만 개인은 떠나지 않았고, 관심이
**"무엇을 살까" → "어디에 넣어둘까(파킹형·커버드콜·채권혼합)"와 "연금·ISA로 어떻게 굴릴까"**로 옮겨갔습니다.
주제 선택을 이 흐름에 맞춥니다. (출처는 `docs/블로그-근거데이터.md` 1장)

### 1-2. 네이버: 검색 유입이 구조적으로 줄고 있음

- AI 브리핑과 AI탭이 검색 결과 첫 화면을 차지하면서, 검색 결과를 클릭하지 않고 끝나는
  '제로클릭'이 늘었습니다. 일부 블로거는 방문자와 조회수가 **작년의 절반 수준**으로 줄었다고
  하고, **수익이 40% 줄었다**는 보도도 있습니다 (ZDNet 2026-08, 네이트 2026-08).
- 대신 **홈판(주제판·인기글·홈피드)은 여전히 블로그 중심**입니다.
- **AI 브리핑 인용 수**는 2026년 1월부터 누적 집계되고 있고, 네이버 메이트 선정에도 반영됩니다.
- 네이버가 공개한 AI 브리핑 인용 원칙은 다섯 가지입니다: **직접 경험한 지식 / 일관된 주제 /
  거짓 없는 진정성 / 읽기 쉬운 구조 / 최신성 유지**. 짜깁기 글, 기계적으로 생성한 글,
  홍보성 글은 인용에서 빠집니다.
- 출처를 밝힌 글이 인용되는 비율이 높다는 분석이 있습니다 (최대 50%).

- **공식 수치**: 통합검색에서 AI 브리핑이 뜨는 비율은 2025년 말 20%입니다. 네이버는 이를
  **2026년 말까지 약 40%**로 늘릴 계획입니다. AI 브리핑이 인용하는 콘텐츠의 **70%가 블로그·카페·지식iN** 같은 네이버 자체 콘텐츠입니다.
- **네이버 메이트**(2026-06 시작): AI 브리핑 인용 실적을 중심으로 **매월 약 3,000명**을 뽑아
  월 30만 원 이상을 지원합니다.

→ **해석**: 네이버에서는 이제 "검색 상위 노출"만 노리면 안 됩니다.
**AI 브리핑에 출처로 인용되는 것**과 **홈피드 노출** 두 가지가 핵심입니다.

### 1-3. 티스토리: 주 유입원은 구글

- **검색 점유율은 측정 기관마다 크게 다릅니다.**
  - 인터넷트렌드(2026 상반기): **네이버 64.3%**, 구글 28.4%, 다음 2.9%
  - StatCounter(2026년 3월): 구글 46.8%, 네이버 44.0%
  - 처음 문서에는 StatCounter 수치만 적었는데, 이를 바로잡습니다.
  - 어느 기준이든 **다음은 3% 미만**이므로, 티스토리 유입은 사실상 구글에 달려 있습니다.
- 티스토리는 2026-05-08 **업스테이지로 운영사가 바뀌었습니다**. 정책이 바뀔 위험이 있습니다.
- 구글에서 AI 요약이 뜨면 1위 결과의 클릭률이 **-58%** 떨어집니다(Ahrefs). 반면 AI 요약에 인용된 사이트는
  인용되지 않은 사이트보다 클릭률이 35% 높습니다(Seer).
- 새 페이지가 1년 안에 구글 상위 10위에 드는 비율은 **1.74%**입니다(Ahrefs 2025). 티스토리 성과는 12~24개월을 보고 운영해야 합니다.
- 금융은 구글이 **YMYL**(돈·건강처럼 삶에 큰 영향을 주는 주제)로 분류해 신뢰(Trust)를 가장 엄격하게 봅니다.
  작성자 소개, 출처, 갱신일이 없는 금융 글은 순위가 잘 오르지 않습니다.

→ **해석**: 노력을 **네이버 약 70%, 티스토리 약 30%**로 나눕니다. 티스토리는 AI가 요약하기 어려운 글에 집중합니다
(비교표, 계산 예시, 정책 원문 해설). 네이버 글을 그대로 복사하면 중복 문서가 되어 **두 블로그 모두 손해**를 봅니다.

추측 대신 데이터로 원인을 좁히는 단계입니다. 뽑은 값은 트래커의 `기준값` 시트에 입력하세요.

### 2-1. 뽑아야 할 데이터

| 플랫폼 | 위치 | 볼 것 |
|---|---|---|
| 네이버 | 블로그 관리 → 통계 → 유입분석 | 검색 / 홈피드 / 이웃 / 외부 유입 비율, **유입 검색어 상위 20개** |
| 네이버 | 통계 → 조회수 순위 | 최근 90일 조회수 상위 10개 글 (무엇이 먹혔나) |
| 네이버 | 통계 → 사용자 분석 | 평균 사용 시간, 재방문율 |
| 네이버 | 서치어드바이저 | 수집 오류 여부, 사이트맵 |
| 네이버 | AI 활용 설정 / 통계 | **AI 브리핑 인용 수** |
| 티스토리 | 관리 → 통계 → 유입 경로 | 구글 / 다음 / 네이버 / 직접 유입 비율 |
| 구글 | 서치콘솔 → 실적 (최근 3개월) | 노출수, 클릭수, CTR(클릭률), 평균 게재순위, **색인 생성된 페이지 수** |
| 구글 | 서치콘솔 → 페이지 | "크롤링됨 - 현재 색인이 생성되지 않음" 페이지 수 |

### 2-2. 원인 판별표

| 증상 | 가능성 높은 원인 | 우선 조치 |
|---|---|---|
| 서치콘솔 **노출수 자체가 적음** | 색인 누락, 키워드 수요가 적음 | 사이트맵 제출, 색인 요청, 키워드 재선정 (3장) |
| **노출은 많은데 CTR이 1% 미만** | 제목과 설명이 매력적이지 않음 | 제목 공식 적용 (4-3), 메타 설명 작성 |
| **평균 게재순위가 20위 밖** | 권위 부족, 글이 얕음 | 주제 클러스터 구성, 기존 글 보강 |
| 네이버 **검색 유입 비율이 급감** | AI 브리핑이 클릭을 흡수 | AI 브리핑 인용 구조로 글쓰기 (4-2), 홈피드 공략 |
| 유입 검색어가 **주제와 무관** | 주제 일관성 부족 (C-Rank 약화) | 발행 주제를 ETF·금융으로 좁히고, 벗어난 글은 비공개 검토 |
| 조회수 대비 **체류 시간이 짧음** (1분 미만) | 첫 화면에 결론이 없음, 가독성 문제 | 결론 먼저 쓰기, 표와 요약 박스 넣기 |
| 네이버와 티스토리에 **같은 글** | 중복 문서 | 플랫폼별로 다시 쓰기 (5장) |

## 3. 키워드 전략: 주제 클러스터

**허브 글 1개 + 세부 글 5~8개**를 묶고 서로 링크합니다.
한 주제를 깊게 다뤄야 C-Rank(네이버)와 주제 권위(구글)가 함께 올라갑니다.

| 클러스터 | 허브 글 (길고 종합적) | 세부 글 (검색 의도 하나씩) | 시즌성 |
|---|---|---|---|
| **A. ISA** | ISA 완벽 가이드 2026 (개편 반영) | ISA 개편 철회 정리 / 생산적금융 ISA vs 일반 ISA / ISA에 담기 좋은 ETF / ISA 만기 연금 이체 / 중개형·신탁형 비교 | 연중 수요, **9~12월 급증** |
| **B. 연금·절세** | 연금저축·IRP ETF 투자 가이드 | 세액공제 한도 계산 / 연금계좌 가능·불가 ETF / 연말 절세 체크리스트 / 퇴직연금 안전자산 30% 규칙 | **11~12월, 1~2월 (연말정산)** |
| **C. 배당·월배당 ETF** | 고배당·월배당 ETF 총정리 | 커버드콜 ETF 구조와 위험 / 분배금 지급일 캘린더 / 고배당 ETF 세후 수익 비교 | 12월 배당 기준일 |
| **D. 테마 ETF** | 2026 유망 테마 ETF 지도 | AI·반도체 ETF 비교 / 신규 상장 ETF 월간 정리 / 총보수 비교 | 신규 상장 시점 |
| **E. 정책 속보** | 월간 금융정책 브리핑 | 세제개편안 진행 상황 / 금리 결정 요약 / 제도 시행일 캘린더 | 발표 당일 |

**키워드 고르는 기준**
- 네이버: 검색광고 키워드도구의 월간 검색수 **1,000~30,000** 구간에 있는 롱테일 키워드
  (예: "생산적금융 ISA 가입조건", "ISA 만기 연금 이체 방법")
- 구글: 서치콘솔에서 **게재순위 8~20위 + 노출 많음** 키워드를 먼저 공략 (가장 적은 노력으로 1페이지 진입)
- 트래커의 `키워드백로그` 시트에서 `우선순위 점수 = 검색수 점수 × 시즌 가중치 ÷ 경쟁도`로 자동 정렬

## 4. 글쓰기 표준 (모든 글에 적용)

### 4-1. 공통 구조

1. **첫 3줄에 결론**: 질문에 대한 답을 먼저 씁니다 (AI 브리핑 인용과 구글 추천 스니펫 모두에 유리)
2. **기준일 표기**: "2026-09-28 기준, 9/1 국무회의 정부안 반영"
3. **표 1개 이상**: 비교표나 수치표 (ETF명, 총보수, 분배율, 순자산)
4. **출처 링크**: 기획재정부·금융위원회 보도자료, KRX, 운용사 공시
5. **직접 경험**: 내 계좌 화면 캡처(민감 정보는 가림), 직접 해본 계산, 실제로 겪은 절차
6. **FAQ 3개**: 실제 검색어 형태로 ("ISA 중도인출 하면 세금 내나요?")
7. **관련 글 링크 2~3개**: 같은 클러스터 안의 글
8. **면책 문구**: "투자 권유가 아니며, 투자 판단의 책임은 본인에게 있습니다"
   (금융 YMYL 신뢰 신호이면서 분쟁 예방 수단)

### 4-2. 네이버 AI 브리핑 인용을 위한 포인트

- 소제목을 **질문형**으로 쓰기 ("생산적금융 ISA는 누가 가입할 수 있나?"), 바로 아래에 **2~3문장 답변**
- 숫자, 날짜, 조건을 **목록이나 표**로 정리 (AI가 추출하기 쉬운 형태)
- 정책이 바뀌면 **기존 글을 수정**하고 "업데이트: 날짜" 표기 (최신성은 인용 원칙 중 하나)
- 주제 이탈 금지: 발행 글의 90% 이상을 ETF·금융으로 유지 (일관된 주제도 인용 원칙 중 하나)

### 4-3. 제목 공식

`[핵심 키워드] + [구체적 숫자나 날짜] + [독자가 얻는 것]`

| 나쁜 예 | 좋은 예 |
|---|---|
| ISA에 대해 알아보자 | ISA 개편 철회 총정리 (9/1 확정): 기존 가입자가 할 일 3가지 |
| 고배당 ETF 추천 | 고배당 ETF 7종 분배율·총보수 비교 (2026년 10월 기준) |
| 연금저축 절세 | 연금저축 세액공제 최대 148.5만 원 받는 법: 12월 31일 마감 체크리스트 |

### 4-4. 하지 말아야 할 것

- AI로 만든 글을 **검수 없이** 그대로 발행 (인용 제외 사유이자, 구글의 저품질 콘텐츠 정책 위반)
- 뉴스를 요약만 한 글 (다른 글과 차별점이 없으면 인용되지 않음)
- 특정 종목 매수 권유 표현 ("무조건 사세요", "수익 보장")
- 브랜드커넥트나 협찬 글에 광고 표기 누락

## 5. 플랫폼별 운영 방식

| 구분 | 네이버 블로그 | 티스토리 |
|---|---|---|
| 목표 유입 | **AI 브리핑 인용** + 홈피드 + 이웃 | 구글 검색 (다음은 3% 미만) |
| 글 성격 | 경험 중심, 가독성, 시의성 (속보, 체험기) | 종합 가이드, 상시 수요(에버그린) 글, 비교표 |
| 길이 | 1,500~2,500자 + 이미지 5~8장 | 3,000~5,000자, 목차 포함 |
| 노력 배분 | **약 70%** | **약 30%** |
| 발행 빈도 | 주 2~3회 | 주 1회 (+ 기존 글 업데이트 1회) |
| 핵심 설정 | 주제를 "경제·비즈니스"로 통일, 서치어드바이저 등록 | 서치콘솔 등록, 사이트맵 제출, 메타 설명, 작성자 소개 페이지 |
| 교차 활용 | 티스토리 가이드를 **짧게 다시 써서** 요약본 발행 + 원문 링크 | 네이버 속보 주제를 **깊게 확장**해 가이드로 발행 |

**같은 주제, 다른 글**: 한 주제로 네이버에는 "경험·속보" 버전, 티스토리에는 "종합 가이드" 버전을 씁니다.
문장을 복사하지 않습니다.

**티스토리 기술 점검 (1주차에 한 번)**
- [ ] 구글 서치콘솔 소유권 확인, `sitemap.xml` 제출
- [ ] 다음 웹마스터도구, 네이버 서치어드바이저에도 등록
- [ ] 스킨이 모바일 친화적인지, 로딩 속도(PageSpeed Insights 모바일 50점 이상) 확인
- [ ] 글마다 메타 설명(요약) 입력, 대표 이미지 alt 텍스트 입력
- [ ] 작성자 소개 페이지: 투자 경력, 운영 계좌, 다루는 범위, 면책 문구 (E-E-A-T)
- [ ] 카테고리를 클러스터(A~E) 단위로 재정리

## 6. 12주 실행 계획

| 주차 | 기간 | 할 일 | 발행 (네이버 / 티스토리) |
|---|---|---|---|
| 1 | 10/05~10/11 | **진단** (2장), 기술 점검, 키워드 백로그 30개 작성 | 2 / 1 — ISA 개편 철회 정리 (속보, **가장 먼저**) |
| 2 | 10/12~10/18 | 기존 상위 글 **리라이팅** 시작 (결론 먼저, 표, 기준일, FAQ) | 3 / 1 — 파킹형 ETF 비교 (금통위 10/22 전) / ISA 허브 글 (티스토리) |

| 4 | 10/26~11/01 | **1차 점검**: CTR 낮은 글 제목 수정 | 2 / 1 — 분기 분배 기준일 안내, 금통위 결과 |
| 5 | 11/02~11/08 | 연말정산 미리보기 개시에 맞춰 연금 글 업데이트 | 3 / 1 — 연말 절세 체크리스트, ISA→연금 이체 |
| 6 | 11/09~11/15 | 클러스터 A 완성 | 2 / 1 — 생산적금융 ISA vs 일반 ISA, 잠자는 ISA 활용법 |
| 7 | 11/16~11/22 | 클러스터 C (방어형) | 3 / 1 — 커버드콜 ETF 분배율과 원금 훼손 위험 |
| 8 | 11/23~11/29 | **2차 점검**: 게재순위 8~20위 글 보강. 세법 속보 초안 작성 | 2 / 1 — 금통위(11/26) 결과, 미국지수 ETF 비교 |
| 9 | 11/30~12/06 | 세법 처리(법정기한 12/2) → **당일 속보** + 기존 ISA 글 전부 업데이트 | 3 / 1 |
| 10 | 12/07~12/13 | "배당기준일이 바뀌었다" 해설 | 2 / 1 |

| 12 | 12/21~12/27 | **최종 점검**, 2027년 1분기 계획 (생산적금융 ISA 가입, 연말정산 간소화) | 2 / 1 |

합계: 네이버 약 30편, 티스토리 약 12편, 기존 글 업데이트 매주 1편 이상.

> **2차 개정에서 바뀐 점**
> - **발행량을 줄였습니다**: 주 5편 → 주 3~4편. 줄인 만큼 기존 글 업데이트에 씁니다.
>   - 근거 1: 2,000단어 이상 작성자의 39%가 "강한 성과"를 보고했고, 전체 평균은 21%입니다(Orbit Media 2025).
>   - 근거 2: 옛 글을 최적화하면 검색 조회수가 평균 +106% 늘었습니다(HubSpot).
> - **연금 클러스터를 6주차에서 3주차로 앞당겼습니다.** 연금 입금이 몰리는 11~12월 전에 글이 색인되게 하기 위해서입니다.
> - **파킹형 ETF, 금통위, 분배 기준일을 새로 넣었습니다.** 모두 확인된 수요와 일정에 맞춘 주제입니다.

### 매주 30분 점검 루틴 (매주 일요일)

1. 트래커 `주간KPI` 시트에 지난주 수치 입력 (네이버 통계, 티스토리 통계, 서치콘솔)
2. `글별성과` 시트에 이번 주 발행 글 추가, 발행 2주 지난 글은 조회수와 순위 기록
3. 판단 규칙:
   - 발행 2주 후 조회수가 하위 30%인 글 → 제목과 첫 문단 수정
   - 서치콘솔 노출 100 이상, CTR 2% 미만 → 제목과 메타 설명 수정
   - 게재순위 8~20위 → 본문 보강 (표, FAQ, 경험 추가)
   - 정책 변경 발생 → 관련 글 48시간 안에 업데이트
