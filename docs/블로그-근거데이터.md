- **수집 방법**: 웹 검색으로 약 150회 조회했습니다. 한국거래소, 네이버 데이터랩, 구글 트렌드,
  언론사 원문 사이트는 작업 환경의 네트워크 정책에 막혀 있어 **원문 페이지를 직접 열지 못했습니다**.
  모든 수치는 검색 결과에 나온 문구를 근거로 적었습니다.
  **블로그 글에 인용할 때는 원문 링크를 한 번 열어 숫자를 확인하세요.**
- **신뢰도 표기**
  - ✅ **교차확인**: 서로 다른 출처 2곳 이상이 같은 수치를 제시함
  - ◻ **단일출처**: 한 곳에서만 확인함

  - ❌ **미확인**: 찾지 못함. 추정해서 채우지 않았습니다
- **확보하지 못한 것**: 키워드별 월간 검색량(네이버 검색광고 키워드도구 기준)은 인용할 수 있는
  수치를 **한 건도** 찾지 못했습니다. 블랙키위, 로워드, 키워드도구에서 직접 조회해야 합니다.
